# Placebo — Gemma Explanation Layer & Guardrails

## 1. Prompt Contract
Placebo enforces a strict prompt contract:
- The LLM receives **only the structured Evidence Package JSON**.
- The LLM **never calculates or alters numbers**.
- The deterministic verdict (`CONFIRMED`, `INCONCLUSIVE`, `REFUTED`) is locked and cannot be overridden by the model.

## 2. Guardrail Enforcement
Every response generated by the model passes through `placebo.llm.guardrails`:
1. **Contradiction Detection:** If a model claims an analysis was confirmed when the verdict is `REFUTED`, the guardrail triggers and reverts to the deterministic ground-truth summary.
2. **Schema Adherence:** Output is parsed into `GroundedExplanation` with explicit fields for headline, what was tested, what was observed, and recommendations.
3. **Graceful Offline Fallback:** If API credentials are not set or the provider experiences network latency, Placebo generates a deterministic explanation immediately with zero delay.
